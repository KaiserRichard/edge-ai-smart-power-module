# Learning curriculum

User-requested sequence, recorded 2026-09-26. These are planned lessons, not completion claims. Use current V1A files as concrete examples and connect design choices to failure modes and measurable acceptance criteria.

| Lesson | Focus |
| --- | --- |
| 0 | Whole-board architecture |
| 1 | Input protection |
| 2 | LM61460 synchronous buck |
| 3 | Independent output protection |
| 4 | Shunt + INA228 monitoring |
| 5 | Raspberry Pi power delivery, connectors, and harness |
| 6 | Power-electronics printed circuit board (PCB) layout |
| 7 | Bring-up, measurement, and characterization |
| 8 | Wheel-Biped Robot (WBR) integration and future smart-power research |

For a new concept, explain what it is, why it matters here, a minimal example, common mistakes, and a way to test understanding. Classify deeper topics as Must Know, Good to Know, or Skip For Now when useful. Prefer design-review depth over elementary circuit tutorials. Discussing later lessons does not authorize later engineering gates.
