# Smart DC Power Module for Edge AI Devices

University Project II hardware project focused on designing and validating a reusable smart DC power module for Edge AI / Edge Computing devices.

## V1 scope

- DC input
- input protection
- reverse-polarity protection
- high-current 5 V DC/DC conversion
- voltage/current/power/energy monitoring
- I2C telemetry
- test points and reusable load output

## Status

Early research and architecture stage.
